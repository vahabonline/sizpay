# WHMCS Sizpay Payment Gateway Module

[English](#english) | [فارسی](#فارسی)

---

## English

A lightweight, secure, and production-ready payment gateway module integrating **Sizpay** smart payment services into the WHMCS platform.

### ✨ Key Features
* **Secure API Integration:** Fully compatible with the latest Sizpay API standards.
* **Dual Currency Support:** Smooth handling of both **Rial** and **Toman**.
* **Detailed Transaction Logging:** Automatically records Gateway Transaction IDs, status codes, and tracking numbers in WHMCS for easy auditing.
* **Instant Callback Verification:** Real-time invoice approval immediately after successful user redirection.

### 🚀 Installation & Setup
1. Upload the content of the repository to your WHMCS directory under:
   `/modules/gateways/`
2. Log in to your WHMCS Admin Area.
3. Navigate to **Setup** > **Payments** > **Payment Gateways** (or System Settings > Payment Gateways).
4. Under the **All Gateways** tab, find and click on **سیزپی - وهاب آنلاین** to activate it.
5. Enter your Sizpay Merchant ID / API Credentials, configure your currency settings, and click **Save Changes**.

## فارسی

ماژول استاندارد، امن و بهینه برای اتصال سیستم مدیریت کاربران WHMCS به درگاه پرداخت هوشمند و کشوری **سیزپی (Sizpay)**.

### ✨ ویژگی‌های کلیدی
* **اتصال امن و پایدار:** توسعه داده شده بر اساس آخرین مستندات و متدهای API سیزپی.
* **پشتیبانی از واحدهای پولی:** سازگاری کامل با واحدهای پولی **تومان** و **ریال** در سیستم.
* **ثبت دقیق لاگ‌ها:** ذخیره و ثبت خودکار توکن تراکنش، کد پیگیری و وضعیت پرداخت در لوک‌آپ‌های WHMCS جهت مانیتورینگ دقیق.
* **تایید آنی (Callback):** پردازش و تایید اتوماتیک و آنی صورت‌حساب‌ها بلافاصله پس از پرداخت موفق کاربر در درگاه.

### 🚀 نحوه نصب و راه‌اندازی
1. فایل‌های ماژول را در مسیر زیر در هاست خود آپلود کنید:
`/modules/gateways/`
2. وارد پنل مدیریت WHMCS شده و به مسیر **تنظیمات سیستم > پرداخت‌ها > درگاه‌های پرداخت** بروید.
3. از تب **All Gateways** (تمامی درگاه‌ها)، درگاه **سیزپی - وهاب آنلاین** را پیدا کرده و روی آن کلیک کنید تا فعال شود.
4. اطلاعات دریافتی از سیزپی (مانند Merchant ID یا کلید API) را وارد کرده، واحد پولی را تنظیم کنید و دکمه ذخیره تغییرات را بزنید.
